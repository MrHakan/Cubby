# Cubby

Cubby is a game made by Unity 2020.3. Project created at 6 August 2021 14:00.

## Game Controls

- W, ↑, {Space} - for Jump
- A, ← - for go Left
- D, → - for go Right

## How to play
- Get all of the yellow points.
- Then go to finish line (there is an big arrow for finish line)

## Extra features
- Double jump
- Wall climbing
- S-Ball: makes you small and your mass decreases
- N-Ball: makes you normal and your mass gets normal
- B-Ball: makes you big and your mass increases a lot
